# TabRise privacy policy

Effective date: 29 October 2026

TabRise is a free, open source Chrome extension by Dennis Petri. Its purpose is to move newly created, ungrouped tabs to the first position below pinned tabs.

## Data handling

TabRise does not collect, retain, sell, or transmit personal data. It has no analytics, advertising, user accounts, cookies, or tracking tools.

To perform its function, it processes tab identifiers, window identifiers, tab positions, pinned state, and tab group state locally in Chrome. These values are used in memory to move tabs. They are not sent to Dennis Petri or any external service and are not saved by the extension.

TabRise does not read website content, tab titles, website URLs, browsing history, messages, passwords, financial information, or location data. It requests no browser permissions or website access and executes no remotely hosted code.

## External links

The extension menu includes an optional link to its GitHub repository. Opening that link visits GitHub, whose own privacy policy applies. TabRise makes no background network requests.

## Changes

If TabRise's data handling changes, this policy will be updated before the changed version is published.

## Contact

For privacy questions, contact Dennis Petri at hi@dennispetri.nl. For general feedback, use https://github.com/dnnsptri/tabrise/issues. Avoid including private information in public issues.
